# NEON AFTERHOURS

Небольшая браузерная top-down action-игра в неоновой криминальной эстетике: ночной город, ограбление ломбарда, погоня и финальный тайник.

## Запуск
1. Скачай или клонируй репозиторий.
2. Открой `index.html` в современном браузере.
3. Для публикации на GitHub включи **Settings → Pages → Deploy from a branch → main / root**.

Сборка и сервер не нужны. Визуал и звуки генерируются кодом; шрифты Google Fonts подгружаются при наличии интернета.

## Управление
- `WASD` или стрелки — движение
- `Shift` — бег
- Мышь — прицел
- Левая кнопка мыши — стрельба
- `E` — взаимодействие с целью
- `Esc` — пауза

## Сохранения
- Автосохранение происходит в `localStorage` браузера примерно каждые 12 секунд и после этапов.
- Кнопки «СОХРАНИТЬ» и «ЗАГРУЗИТЬ» управляют локальным сохранением.
- Чтобы перенести сохранение между браузерами/устройствами, открой DevTools → Console и выполни:
  ```js
  copy(localStorage.getItem('neonAfterhoursSave'))
  ```
  Сохрани полученный JSON в файл. Для загрузки выбери JSON через поле `saveFile` (можно временно добавить кнопку/импорт в интерфейс; локальный слот сохраняется автоматически).

## Структура
- `index.html` — интерфейс и игровое поле
- `style.css` — оформление
- `game.js` — игровой цикл, логика, миссии, сохранения
